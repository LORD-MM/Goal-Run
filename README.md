# Goal Run

A simple 2D football game made in Unity. You control a player on the pitch:

- **Collect balls** that come onto the pitch from the top
- **Avoid defenders** that run across the pitch
- **Score a goal** when the goal appears

**Status:** Work in progress.

## Details
- **Unity version:** Unity 6.6 (6000.6.0f1)
- **Controls:** WASD / arrow keys to move in all directions
- **Input:** New Input System
- **Scene:** `Assets/Scenes/Goal_Run_0.unity`
